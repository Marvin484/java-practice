# Number Guessing Game

## Description

A simple Java command-line game where the computer generates a random number between 1 and 100. The player tries to guess the number with hints provided after each guess.

## Features

- Random number generation (1-100)
- Higher/lower feedback after each incorrect guess
- Tracks number of attempts
- Option to play multiple rounds

## How to Run

1. Compile the program:

```bash
javac week01/day06/NumberGame.java
```

2. Run the program:

```bash
java week01.day06.NumberGame
```
